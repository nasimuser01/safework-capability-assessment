# SafeWork NSW – Capability Assessment Form

An accessible, responsive web form built with HTML, SCSS and vanilla JavaScript.

## Run locally

```bash
npm install
npm run build:css   # compiles src/styles.scss -> css/styles.css
```

Then open `index.html` in a browser.

## Structure

```
index.html        – form markup
script.js         – validation and conditional-field behaviour
src/styles.scss   – source styles (NSW Design System colour tokens)
css/styles.css    – compiled output (committed so the site can be hosted statically)
```

_Design approach, key choices and accessibility notes will be documented here in a later step._
